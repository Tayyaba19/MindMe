# MindMe – Conversational Knowledge Assistant with Graph Visualization

MindMe is a conversational AI assistant built using `Streamlit` and powered by `LightRAG` (Retrieval-Augmented Generation). It allows users to interact with their data in natural language and visualize the underlying knowledge structure using an interactive **knowledge graph** built with `pyvis` and `networkx`.

##  Features

### 1. Conversational RAG Interface
- The assistant is powered by `LightRAG`, which combines:
  - **LLM**: Uses OpenAI's `gpt-4o-mini` for reasoning and answering
  - **Embedding**: OpenAI embedding model to semantically encode documents
  - **Storage**: Documents are inserted into RAG's knowledge base via `ainsert()` and then queried via `rag.query()`
- The user provides input through a `Streamlit` interface, and the assistant replies with context-aware responses, using the last 5 conversation turns for maintaining continuity

### 2. Knowledge Graph Viewer
- The system loads a `GraphML` file (`graph_chunk_entity_relation.graphml`) that represents entity relationships from the documents
- It visualizes this using `pyvis` and `networkx`:
  - Nodes are randomly color-coded
  - If available, each node and edge can display its `description` as a tooltip
  - The graph is saved as `knowledge_graph.html`
- The user can view this graph from within the Streamlit UI by clicking **"Show Knowledge Graph"**, which loads and displays the generated HTML interactively

##  Project Structure


##  Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/Tayyaba19/MindMe.git
cd MindMe
```

2. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
```

3. Install required packages:
```bash
pip install -r requirements.txt
```

4. Set up your OpenAI API key:
   - Create a `.env` file in the root directory
   - Add your OpenAI API key to the file:
   ```
   OPENAI_API_KEY=your_api_key_here
   ```

##  How to Run

```bash
streamlit run main.py
```

##  Usage

1. After launching the app, you can interact with the assistant by typing your questions or commands in the chat input
2. To view the knowledge graph visualization, click on the **"Show Knowledge Graph"** button
3. The system will automatically use the RAG framework to provide context-aware answers based on the underlying data

## 📝 Note

Ensure your OpenAI API key has access to the `gpt-4o-mini` model and embedding models for the application to function correctly.
